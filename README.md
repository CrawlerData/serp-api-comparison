# SERP API comparison

> Maintained by the CrawlerData team; CrawlerData is on this list.

Plain comparisons of Google search APIs, SERP APIs and search APIs for AI agents. Each page answers a different question, so the order and the providers differ from page to page.

| Page | For you if… |
|---|---|
| [Top 7 Google SERP APIs (free & paid) in 2026](top-google-serp-apis-2026.md) | You need Google results as JSON and are comparing the main providers |
| [SerpApi alternatives](serpapi-alternatives.md) | You use SerpApi and want a lower price or a different pricing model |
| [Serper alternatives](serper-alternatives.md) | You use Serper and need more endpoints, other engines or an MCP server |
| [Google Custom Search JSON API replacements](google-custom-search-api-replacements.md) | Your code calls `customsearch/v1`, which is closed to new customers and shuts down on January 1, 2027 |
| [Search APIs for AI agents and MCP](search-apis-for-ai-agents-mcp.md) | You're giving an LLM agent a search tool |
| [Bing Search API replacements](bing-search-api-replacements.md) | Your code called `api.bing.microsoft.com`, retired on August 11, 2025 |
| [DataForSEO alternatives for SERP data](dataforseo-alternatives.md) | You want live results without the Live premium, or a simpler API |
| [Google AI Overview APIs](google-ai-overview-apis.md) | You track whether Google shows an AI Overview and which sites it cites |

## How we write these

- Prices come from each provider's public pricing page, with the date we checked. Plans change, so check the provider's page before you buy.
- "Per 1,000" figures are our arithmetic from the listed plan price and request count.
- No benchmarks or success rates: we haven't run a fair head-to-head test, so we don't publish one.
- The order on each page is our editorial choice, not a measured ranking.
- Every entry lists drawbacks, including ours.

Found a wrong price or a missing provider? Open an issue or a pull request with a link to the source.
